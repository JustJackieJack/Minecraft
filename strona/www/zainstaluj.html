Zainstaluj

Instalator sprawdza skiny, config i mody, a przed każdą zmianą pyta o zgodę. Twoich ustawień (grafika, minimapa, czat głosowy) nie zmienia.

Windows macOS (Apple M) macOS (Intel) Linux

Jak pobrać

  1. Zainstaluj Forge 1.20.1 i uruchom go raz. Zamknij grę.
  2. Wrzuć pobrany plik do folderu minecraft, tam gdzie jest folder mods.
  3. Uruchom go i odpowiadaj na pytania. Odmowa pomija tylko dany krok.

Windows

Folder to zwykle %appdata%\.minecraft. Uruchom plik dwuklikiem. Jeśli pojawi się „System Windows ochronił ten komputer”, wybierz „Więcej informacji”, a potem „Uruchom mimo to”.

macOS

Pobierz wersję zgodną z procesorem komputera: Apple M albo Intel. Folder gry to zwykle ~/Library/Application Support/minecraft. W Terminalu wykonaj (poniżej przykład dla Apple M, dla procesora Intel nazwa pliku kończy się na macos_intel):

cd ~/Library/Application\ Support/minecraft
xattr -d com.apple.quarantine ci_panowie_instalator_macos_arm
chmod +x ci_panowie_instalator_macos_arm
./ci_panowie_instalator_macos_arm

Polecenie xattr zdejmuje blokadę systemu dla pobranego pliku. Jeśli napisze, że nie ma takiego atrybutu, po prostu przejdź dalej.

Linux

Folder gry to zwykle ~/.minecraft. W launcherze Prism otwórz folder minecraft wybranej instancji. W terminalu wykonaj:

cd ~/.minecraft
chmod +x ci_panowie_instalator_linux
./ci_panowie_instalator_linux

Zastępowane i usuwane pliki trafiają do folderu .ci_panowie_kopia, więc nic nie ginie.
